# 사진 이용 허락 요청 초안 — 용인시 도서관사업소

**제목:** [팀명] 공공시설 검색 서비스 '지금가용'의 도서관 외관 사진 이용 허락 요청

안녕하세요. 저희는 [소속/팀명]으로, 용인시 공공 여가시설을 요일·시간대별로 검색하는 웹 서비스 '지금가용'([서비스 주소])을 만들고 있습니다. [행사명·기간 등 개발 배경 한 문장]

서비스는 백엔드 API로 용인시 공공시설 348곳의 운영시간을 제공하고, 검색 결과 카드와 시설 상세 화면에 시설 사진을 보여 줍니다. 지금은 대부분 유형별 기본 그림을 쓰고 있어, 시민이 시설을 알아보기 쉽도록 실제 외관 사진을 쓰고 싶습니다.

용인시 도서관 누리집 각 관 '인사말' 페이지에 게시된 외관 사진 14장(아래 목록)을 서비스에 쓰고자 합니다. 해당 페이지에는 공공누리 표시가 없어, 용인시 저작권정책 안내에 따라 사전에 허락을 구합니다.

### 이용 계획

| 항목 | 내용 |
| --- | --- |
| 이용 범위 | '지금가용' 웹 서비스의 검색 결과 카드(높이 약 180px)와 시설 상세 화면(높이 약 240px) 상단 사진 |
| 이용 형태 | 원본을 그대로 쓰되, 화면 비율에 맞춰 가장자리가 잘려 보일 수 있음(파일 자체는 수정하지 않음) |
| 영리 여부 | [비영리 / 무료 서비스 · 광고 없음 등 실제 상황] |
| 출처 표시 | 예: "사진 출처: 용인시 도서관사업소(lib.yongin.go.kr)" — 원하시는 문구가 있으면 그대로 따르겠습니다 |
| 이용 기간 | [예: 허락일부터 서비스 운영 기간 동안 / 행사 종료일까지] |
| 재배포 | 서비스 화면 표시 외 다른 용도·제3자 제공은 하지 않음 |
| 철회 | 요청하시면 즉시 내리겠습니다 |

### 여쭙고 싶은 점

1. 아래 14장을 위 범위로 이용해도 되는지
2. 허락하신다면 출처 표시 문구, 영리·변경 이용 가능 여부 등 조건
3. 사진 저작권이 도서관사업소가 아닌 다른 분(촬영 업체 등)에게 있다면 그 사실
4. (가능하면) 영덕도서관 외관 사진처럼 누리집에 없는 사진이나, 공공누리를 부착해 개방할 계획이 있는지

## 허락을 받은 뒤 (팀 내부용, 보낼 때는 지우기)

1. 회신 원문(메일 · 공문)을 보관하고, 허락 범위와 출처 문구를 `review-decisions.json`에 시설별로 기록한다
   (`decision: "approve"`, `note`에 허락 일자 · 범위 · 출처 문구 · 회신 보관 위치).
2. 공식 누리집 사진은 지금 수집 스크립트(Wikimedia 전용)로는 받지 않으므로, 허락 범위가 확인되면 적용 방법을 따로 정한다.
3. 출처 표시가 조건이면 화면 어디에 표시할지(상세 화면 사진 하단 캡션 등) 함께 정한다.
